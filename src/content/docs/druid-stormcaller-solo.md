德魯伊（Druid）是進攻型治療者，終局單刷價值來自兩件事：它能用 `Tornado`、`Lightning Blast`、`Blizzard` 這類短冷卻法術輸出，也能在攻擊空檔用 `Nature's Touch` 迅速補血。FC2 德魯伊頁把它描述成能一邊打高火力、一邊用零冷卻治療維持戰線的職業。

> **快速重點**
> `Stormcaller` 德魯伊適合喜歡主動輸出、又想保留治療保險的玩家。
> 核心輸出看 `Tornado`，FC2 提到 Rank 29 時 bonus hit +4、Rank 39 時 bonus hit +5。
> 單刷真正的安全感來自 `Nature's Touch`、抗性與不要貪站位。

## 單刷定位

德魯伊不是板甲職，不能用十字軍或牧師那種硬吃傷害的方式理解。它的穩定來自「縮短危險時間」與「隨時補回失血」：先用元素 AoE 和普通攻擊處理目標，血線掉下來時立刻補 `Nature's Touch`，再回到輸出循環。

| 面向 | 德魯伊的優勢 | 單刷風險 |
| ------ | ------ | ------ |
| 輸出 | `Tornado`、`Lightning Blast`、`Blizzard`、熊拳與短冷卻技能 | 站太前或被控制時，皮甲容錯不如板甲 |
| 治療 | `Nature's Touch` 可在攻擊空檔補血 | 忙著輸出而漏看血條會很危險 |
| 裝備 | `Nylith`、`Cryptic Paragon`、`Arctic Orb` 等 caster / hybrid 候選多 | 需要同時補 `Tornado` rank、抗性、Rare Drop Rate 與資源 |

## 天賦與技能目標

FC2 德魯伊例把天賦樹加成集中在 `Stormcaller`，技能加成主要收集 `Tornado`。要特別注意的是，FC2 說明中增加攻擊次數的是普通 `Tornado`，不是 `Superior Tornado`。

| 技能 / 工具 | FC2 讀法 | 單刷用途 |
| ------ | ------ | ------ |
| `Tornado` | Rank 29 bonus hit +4；Rank 39 bonus hit +5 | 主輸出斷點，優先確認 tooltip 是否達標 |
| `Lightning Blast` | FC2 把 `Superior Lightning Blast` 調到 Rank 19 取得目標數增加 | 第二輸出工具，補元素傷害與多目標 |
| `Blizzard` | FC2 也把 `Superior Blizzard` 調到 Rank 19 | 補冰冷 / AoE 壓力，但成長評價較微妙 |
| `Mastery: Kodiak Spirit` | 後續點數投入方向 | 讓德魯伊的熊形態與普攻價值更完整 |
| `Nature's Touch` | 攻擊空檔補血 | 單刷安全線，不要只當隊伍治療技 |

## 操作循環

進地城後先維持 buff：

```text
Synthesize -> Branch Spirit -> 節奏穩定後 Moss Breath
```

若不嫌麻煩，FC2 提到可以在施放 `Branch Spirit` 前換上 `Superior Branch Spirit` 加成裝，施放後再切回平常裝備。這屬於終局優化，不是新手必做流程。

戰鬥中：

```text
Tornado
Lightning Blast
Blizzard
哪個冷卻結束就先按哪個
血線降低 -> Nature's Touch
```

德魯伊忙起來時很容易一邊看技能冷卻、一邊看畫面下方血條。單刷時不要為了多打一輪 `Tornado` 忘記補血；你不是靠無敵硬吃，而是靠治療與輸出交錯撐住。

## 裝備方向

FC2 德魯伊例以 `King of Riven Grotto` 英雄周回為想定，天賦樹加成看 `Stormcaller`，技能加成收集 `Tornado`，屬性強化以冰冷 Damage 與 Arcane Damage 為主。若想刷 `Ashenflow Peak` 前半，還要另外注意對 Humanoid 的裝備。

| 部位 / 方向 | FC2 關鍵字 | 判斷重點 |
| ------ | ------ | ------ |
| 右手 / 左手 | `Nylith's Crook`、`Cryptic Paragon` | `Nylith` 是 elite set 骨架；`Cryptic Paragon` 若 roll 到 `Tornado` 或關鍵 talent 會很強 |
| 副手 / Charm | `Arctic Orb` | 冰冷傷害與 Rare Drop Rate 候選；要看 roll 是否服務當前路線 |
| 頭部 | `Charlatan's Crest`、`Tortoise Shell Helmet`、`Rephaim's Kepi`、`Hebron's Coif` | 若只差 `Tornado` 斷點，專門頭部可能比泛用頭更有價值 |
| 肩 / 腿 / 戒指 | `Oasis Shroulderguards of Kardis`、`Zamtil's Plenitude`、`Black Swan Band`、`Heaven's Wing` | 抗性、法術傷害、Rare Drop Rate 與生存一起評估 |
| 套裝骨架 | `Nylith` | 不必盲目穿滿；用來撐天賦、抗性與核心 slot |

FC2 也提到，如果肩部、腿甲、戒指附近改用 `Jibekn` 2 / 3 件，可以取得冰冷或閃電 Damage，但抗性會比較難補。這類混搭要等你知道自己缺的是傷害還是生存後再動。

## 單刷優先順序

1. 先讓 `Tornado` 達到可用斷點，再看 `Lightning Blast` 與 `Blizzard`。
2. 補足抗性、生命與資源，不要把德魯伊當板甲職硬扛。
3. 用 `Nature's Touch` 主動維持血線，不要等到殘血才救。
4. `Cryptic Paragon`、`Charlatan's Crest`、`Nylith` 件都要看 roll；名字只是入口。
5. 若刷 undead route，用裝備補對不死生物傷害；若刷 `Ashenflow`，重新檢查 Humanoid 與元素方向。

## 常見失誤

- 誤以為 `Superior Tornado` 才是 FC2 提到的 hit count 斷點。
- 只追冰冷 / Arcane Damage，忽略皮甲職的抗性與控制抗性。
- 有 `Nature's Touch` 卻不看血條，導致補血優勢沒有發揮。
- 把 `Nylith` 當成不能拆的全套；終局仍要比較每個 slot 是否真的服務 `Tornado`。
- 在非 undead route 硬套 Riven Grotto 裝備例，忽略怪物 species 和 traits。
