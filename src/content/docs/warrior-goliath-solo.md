戰士（Warrior）在終局單刷的定位不是「最早舒服」，而是「裝備成形後上限很高」。FC2 戰士頁的核心觀察很直接：戰士是唯一能雙持雙手武器的職業，因此能從兩把高階雙手武器、傳奇裝備或神話製作武器中取得大量屬性與技能收益。這也代表它比十字軍、牧師更吃裝備基礎。

> **快速重點**
> `Goliath` 戰士適合已能穩定刷 `Hell` / `Heroic`、並且願意長期追雙手武器與高價值散件的玩家。
> 單刷核心是開戰前維持 `Frenzy`、`Bulwark`、`Intrepid Shout`，戰鬥中用 `Rupture` 建立出血與物理傷害窗口。
> 它不是低裝最無腦的單刷職業；如果想要第一隻角色穩刷，十字軍或牧師通常更順。

## 單刷定位

FC2 把戰士描述成「很像 Tank 的 Tank」，但也提醒目前玩法較少需要純坦，實戰更像一邊輸出、一邊順手扛住。單刷時這句話很重要：只堆防禦會清太慢，只堆輸出又容易被高壓 traits 打穿，戰士要同時維持傷害、減傷、回復與資源。

| 面向 | 戰士的優勢 | 單刷風險 |
| ------ | ------ | ------ |
| 生存 | plate armor、`Bulwark`、`Frenzy` 戰後回復與高生命裝備 | 魔法 / 物理高壓都要靠裝備補洞，不能只看 armor |
| 輸出 | 雙持雙手武器、`Rupture`、`Furious Cleave`、`Double Throw` | 武器不夠好時，清怪效率會比十字軍 / 牧師更不穩 |
| 裝備收益 | 雙手武器、legendary、mythical、socket 與 all talents 收益高 | 成形前缺資源、命中或 Rare Drop Rate 都會拖慢循環 |

## 天賦與技能目標

FC2 裝備例把天賦樹加成集中在 `Goliath`，技能加成則看 `Rupture`、`Furious Cleave` 與 `Double Throw`。這三個技能把戰士的單刷語言分成三段：先讓敵人出血，再用物理加成窗口補大招，最後用 `Double Throw` 處理後排。

| 技能 / 工具 | FC2 讀法 | 單刷用途 |
| ------ | ------ | ------ |
| `Rupture` | 攻擊次數增加門檻：Rank 10 / 15 / 23 / 31 | 主循環；先上出血，讓後續物理傷害吃到窗口 |
| `Furious Cleave` | 攻擊次數增加門檻：Rank 18 / 24 / 32 | 出血後的主要補傷害工具 |
| `Double Throw` | 攻擊次數增加門檻：Rank 19 / 29 | 對後排有高價值，前排清掉後仍能維持後排加成 |
| `Frenzy` | FC2 配置假設沒有 Enchanter，因此投入較多 | 開戰前 buff；單刷時兼具速度與戰後回復價值 |
| `Bulwark` | 開戰前 buff | 高壓地城的核心減傷工具 |
| `Intrepid Shout` | 開戰前 buff | 提高進場穩定度，和 `Frenzy` / `Bulwark` 一起維持 |

`Whirlwind` 在 FC2 評價較低，原因是即使有 `Mastery: Titan` 觸發，冷卻仍接近 9 秒，手感不佳。單刷頁不要把它寫成主按鍵；更安全的寫法是交給觸發或視版本 tooltip 調整。

## 操作循環

開戰前先補：

```text
Frenzy -> Bulwark -> Intrepid Shout
```

戰鬥中用：

```text
Rupture 建立出血
出血 / 物理加成窗口 -> Furious Cleave
後排或多目標壓力 -> Double Throw
Whirlwind 主要視觸發與 tooltip，不當主循環核心
```

遇到危險 boss 或 traits 時，先確定 `Bulwark` 沒斷，再決定要不要貪 `Furious Cleave`。戰士單刷翻車常不是因為完全沒有防禦，而是為了補輸出忘了 buff、抗性或資源。

## 裝備方向

FC2 戰士例使用本職套裝 0 件，代表終局戰士常用高價值散件堆出真正需要的能力。這不是要玩家一開始就放棄套裝，而是提醒終局判斷要以技能斷點、武器性能、生存與資源為準。

| 部位 / 方向 | FC2 關鍵字 | 判斷重點 |
| ------ | ------ | ------ |
| 雙手武器 | `Korelian Adamantite Maul`、`Zimri's Wisdom`、高階 legendary / mythical 雙手武器 | 戰士最大收益來源；先看 DPS、技能加成、命中、資源與 sockets |
| 副手 / ranged slot | `Demetrium's Ballista`、`Stormcaller Bow` | `Demetrium's Ballista` 只有高 socket roll 才特別有價值；`Stormcaller Bow` 可補天賦 |
| 頭部 / 胴體 | `Uncle Herschel's Visage`、`Gwendolyn's Might`、`Olivia's Chains of Fealty` | `Olivia's Chains of Fealty` 雖是 Normal，但 FC2 評價很高；不要只用階級判斷 |
| 手 / 腰 / 腿 | `Marshal Gauntlets Iniquity`、`Hulking Storm Belt`、`Grezzlon's Legplates` | 力量、attack rating、技能 roll 與生存詞綴都要看 |
| 飾品 | 所有天賦 +2 rare amulet、`Circle of Death`、`Girded Everliving Golem` | 項鍊優先 all talents、力量、passive 或暴擊；戒指依力量、技能與 Rare Drop Rate 取捨 |

在還不能換上高階傳奇武器前，FC2 建議右手 `Korelian Adamantite Maul` 期間可用 1 顆 `Gra` 補命中時 Mana 回復。換成自帶 hit mana recovery 的傳奇武器後，再重新評估 rune 配置。

## 單刷優先順序

1. 先讓 `Frenzy`、`Bulwark`、`Intrepid Shout` 的維持變成習慣。
2. 用裝備把 `Rupture`、`Furious Cleave`、`Double Throw` 推向可用斷點。
3. 追高階雙手武器，但不要為了帳面 DPS 拆掉抗性與資源。
4. `Demetrium's Ballista` 只把高 socket roll 當終局工具裝，普通 roll 不要神化。
5. 進 `Heroic` 後再評估 legendary / mythical 雙手武器與 6 socket base。

## 常見失誤

- 把戰士玩成純坦，導致單刷清怪太慢。
- 太早追雙持雙手上限，卻沒有補抗性、命中與資源。
- 忽略 `Frenzy` 戰後回復，把它只當攻速 buff。
- 把 `Demetrium's Ballista` 寫成固定 6 socket；它是 `Socketed (1-6)`，高 roll 才值得特別留。
- 看到 legendary 就換上，卻沒有比較 `Rupture`、`Goliath` 或資源詞綴是否真的服務 build。
