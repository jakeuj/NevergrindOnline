### Damage 強化

只會出現在武器上的 Mod，用來強化武器 Damage。裝備面板顯示的數值與 DPS，已經包含 Damage 強化後的結果。

<a id="fc2-itemmods-hdr2"></a>

### 攻擊速度增加

只會出現在武器上的 Mod，用來提高武器 Speed。裝備面板顯示的數值與 DPS，已經包含攻擊速度增加後的結果。

<a id="fc2-itemmods-hdr3"></a>

### 格擋率

只會出現在盾牌上的 Mod，表示格擋觸發率。這個數值只是觸發率；格擋時的基礎 Damage 減免率為 25%。另外，坦職會在格擋率上額外加算 20%。

<a id="fc2-itemmods-hdr4"></a>

### 格擋率增加

只會出現在盾牌上的 Mod，用來提高格擋率。裝備面板顯示的格擋率，已經包含格擋率增加後的結果。

<a id="fc2-itemmods-hdr5"></a>

### 物理防禦強化

只會出現在防具上的 Mod，用來強化物理防禦。裝備面板顯示的物理防禦，已經包含物理防禦強化後的結果。

<a id="fc2-itemmods-hdr6"></a>

### 天賦

提高角色對應的天賦。若同一件裝備有多個天賦詞綴，不會抽到相同天賦。這類詞綴常出現在武器、盾牌、副手、頭部、胴體、手套、腰帶、項鍊與戒指上。日文原站中的「才能」與「タレント」都是天賦的機翻，本質上只差在單複數。

- 所有天賦
  提高所有職業的所有天賦。
- 全屬性 職業名稱 天賦
  提高指定職業的所有天賦。
- 天賦樹
  提高指定天賦樹內的所有天賦。
- 屬性天賦
  出血、毒素、Arcane、閃電、火焰、冰冷。提高所有職業中帶有該屬性的天賦。若技能同時有多種屬性，只會套用其中一種。例如德魯伊的 Tornado 同時是冰冷與 Arcane 技能，但只會套用冰冷天賦。
- 天賦
  提高指定天賦。

<a id="fc2-itemmods-hdr7"></a>

### 能力值

全能力值、力量、耐力、敏捷、靈巧、智力、智慧、魅力。

|力量|物理技能傷害與 Attack Rating 提升；對物理技能傷害影響很大。|
|---|---|
|耐力|最大 Health 增加。|
|敏捷|閃避率與物理防禦提升。|
|靈巧|Attack Rating、招架、反擊、格擋率與暴擊率提升；Attack Rating 的提升幅度不如力量。|
|智力|最大 Spirit 與 Conjuration 法術強度提升；也會小幅影響 Evocation 法術強度。|
|智慧|最大 Mana 與 Evocation 法術強度提升；也會小幅影響 Conjuration 法術強度。|
|魅力|最大 Spirit 與 Alteration 法術強度提升。|

<a id="fc2-itemmods-hdr8"></a>

### Passive

全 Passive Skill、攻擊、防禦、單手斬擊、單手鈍器、刺擊、弓術、空手、雙手斬擊、雙手鈍器、雙持、Double Attack、閃避、招架、反擊、Alteration、Conjuration、Evocation。

武器 Passive 對物理技能 Damage 與命中率影響很大，因此重要性很高。粗略估算，武器 Passive 15 大約可讓物理技能 Damage 增加 3.3%。

法術 Passive 對 Spell Damage 的提升不算大，效益較微妙。Alteration 傾向影響恢復等輔助系，Conjuration 傾向影響範圍系，Evocation 傾向影響單體系。

<a id="fc2-itemmods-hdr9"></a>

### 需求

降低裝備需求等級。裝備面板顯示的需求等級，已經包含需求降低後的結果。

<a id="fc2-itemmods-hdr10"></a>

### 暴擊

暴擊率（%）會根據靈巧與暴擊數值計算。靈巧帶來的暴擊率提升會隨著靈巧堆高而遞減，約靈巧 200、暴擊率 10% 附近幾乎不再成長。暴擊數值每增加 50，大約可讓暴擊率增加 2～3%，但同樣會遞減。

暴擊時的傷害倍率基本為：物理攻擊單手武器 150%、雙手武器 200%，魔法則為 150%。假設暴擊數值增加 50、讓暴擊率上升 3%，倍率 150% 時實際傷害約增加 1～1.5%，倍率 200% 時約增加 2～3%。若暴擊率極低，或魔法職不知道該鑲什麼符文，也可以考慮補暴擊。

<a id="fc2-itemmods-hdr11"></a>

### Attack Rating

提高物理技能 Damage 與命中率。以對物理技能的影響來看，Attack Rating 100 大約相當於力量 30～35。

<a id="fc2-itemmods-hdr12"></a>

### 施法速度增加

提高法術施法速度。系統會依施法速度增加數值計算法術施法 Haste（%），再決定實際施法速度。粗略估算，施法速度增加 20 大約會讓法術施法 Haste 增加 2.5%。

<a id="fc2-itemmods-hdr13"></a>

### 資源

Health、Mana、Spirit。以固定值提高各資源；因為是加算，基礎數值越高，相對效益越低。

<a id="fc2-itemmods-hdr14"></a>

### 恢復速度

Health、Mana、Spirit。每 5 秒恢復等同於該數值的資源；不受難度懲罰。

<a id="fc2-itemmods-hdr15"></a>

### 命中時恢復

Health、Mana、Spirit。使用武器普通攻擊或發動物理技能時恢復；多段技能視為一次。此效果會受到難度懲罰：惡夢（Nightmare）減少 33%，地獄（Hell）減少 50%。

<a id="fc2-itemmods-hdr16"></a>

### 擊殺時恢復

Health、Mana、Spirit。敵人死亡時恢復；即使不是自己擊殺也會恢復。不受難度懲罰。

<a id="fc2-itemmods-hdr17"></a>

### 受擊時恢復

Health、Mana、Spirit。受到攻擊時恢復；即使沒有被命中也會恢復。此效果會受到難度懲罰：惡夢（Nightmare）減少 33%，地獄（Hell）減少 50%。

<a id="fc2-itemmods-hdr18"></a>

### 最大資源

Health、Mana、Spirit。以百分比提高各資源上限。

<a id="fc2-itemmods-hdr19"></a>

### Damage 減免

物理、魔法。以固定值扣減受到的 Damage；因為是減算，原本受到的 Damage 越高，相對效益越低。

<a id="fc2-itemmods-hdr20"></a>

### 物理抗性

以百分比降低受到的物理 Damage。這類詞綴常出現在盾牌、頭部、胴體、腰帶與腿甲上。

<a id="fc2-itemmods-hdr21"></a>

### 屬性抗性

全屬性、出血、毒素、Arcane、閃電、火焰、冰冷。依各屬性以百分比降低受到的 Damage；全屬性抗性不包含物理抗性。

上限為 75%，且每個難度都會套用懲罰。合計來看，惡夢（Nightmare）需要堆到 105%，地獄（Hell）需要堆到 145% 才能達到上限。

<a id="fc2-itemmods-hdr22"></a>

### 屬性吸收

出血、毒素、Arcane、閃電、火焰、冰冷。依各屬性，按照受到 Damage 的一定比例恢復 Health。

<a id="fc2-itemmods-hdr23"></a>

### 狀態異常抗性

全狀態異常、眩暈、恐懼、麻痺、沉默。縮短受到狀態異常影響的時間。

上限為 50%，且每個難度都會套用懲罰。合計來看，惡夢（Nightmare）需要堆到 60%，地獄（Hell）需要堆到 75% 才能達到上限。

<a id="fc2-itemmods-hdr24"></a>

### 近戰 Damage

出血、毒素、Arcane、閃電、火焰、冰冷。為普通攻擊與物理技能 Damage 加算固定數值；因為是加算，基礎 Damage 越高，相對效益越低。

<a id="fc2-itemmods-hdr25"></a>

### Spell Power

全、出血、毒素、Arcane、閃電、火焰、冰冷。為 Spell Damage 加算固定數值；因為是加算，基礎 Damage 越高，相對效益越低。

<a id="fc2-itemmods-hdr26"></a>

### 屬性 Damage

全 Spell、出血、毒素、Arcane、閃電、火焰、冰冷。提高各屬性 Damage；雖然寫作全 Spell，但也對物理技能有效。

推測會和天賦、裝備上的 Skill Damage 強化加在同一個乘區；若 Skill Damage 強化已經堆得很高，效率會逐漸下降。粗略估算，可視為約 1/6 的實際 Damage 增幅。

<a id="fc2-itemmods-hdr27"></a>

### 降低敵人抗性

全、出血、毒素、Arcane、閃電、火焰、冰冷。上限為 75%。降低敵人的屬性抗性；不會影響隊友。粗略估算，可視為約 1/3 的實際 Damage 增幅。

<a id="fc2-itemmods-hdr28"></a>

### 移動速度

提高地城內的移動速度；上限為 500%。

<a id="fc2-itemmods-hdr29"></a>

### 獲得率

Rare Drop Rate、Gold 取得率、經驗值取得率。提高各項取得率；Gold 取得率也會影響寶箱。

<a id="fc2-itemmods-hdr30"></a>

### Damage 強化 vs 類型

Humanoid、Beast、Undead、Demon、Dragonkin、Mystical、Giant。提高對各怪物類型造成的 Damage。物理技能推測與 Skill 強化、屬性 Damage 強化同乘區，實際 Damage 增幅約為 1/6；魔法技能則會依倍率提高 Damage，推測屬性抗性與降低抗性會重複套用。

<a id="fc2-itemmods-hdr31"></a>

### Skill 強化

提高 Skill Damage。若同一裝備上有多個 Skill 強化，抽到相同 Skill 強化時會加算。若屬性 Damage 或 Skill 強化已經堆得很高，效率會逐漸下降。粗略估算，可視為約 1/6 的實際 Damage 增幅。

### 效果

發動普通攻擊時，有機率觸發追加效果；即使命中判定失敗也會觸發。

效果 Damage 由固定 Damage + Lv * n 決定，不受抗性等因素影響。不過 DoT 類效果會受抗性影響，也可能發生暴擊。

<a id="fc2-itemmods-hdr33"></a>

### 乙太

武器 Damage 提高 33%，防具防禦力提高 50%。戰鬥結束時有低機率消耗耐久度；耐久度歸零時裝備會消失。

<a id="fc2-itemmods-hdr34"></a>

### 不滅

有不滅時，乙太裝備的耐久度不會下降。可透過 Fyrm 符文賦予不滅；部分 Set 或傳奇（Legendary）裝備也會固定帶有不滅。若裝備沒有乙太，不滅本身沒有特別意義。

<a id="fc2-itemmods-hdr35"></a>

### Socket

武器、副手、頭部與胴體裝備可能帶有 Socket，可依 Socket 數量鑲嵌符文。符文一旦鑲上，就無法取下或移除。

## 神話製作（Craft）

- FC2 file：[mythical.html](https://atelier3.web.fc2.com/ngo/mythical.html)
- 原站 Last-Modified：`Thu, 26 Jun 2025 00:26:03 GMT`

可在鐵匠鋪的 Craft 分頁製作 Mythical 物品，也就是 Rune Word（符文組）系統。

<a id="fc2-mythical-基本"></a>

### 基本

<a id="fc2-mythical-製作方法"></a>

#### 製作方法

背包中同時持有要作為素體的裝備與所需符文，選取素體後按下製作按鈕即可製作。

製作時不需要先把符文插進素體的 Socket。

<a id="fc2-mythical-素材"></a>

### 素材

![white.jpg](/fc2-assets/ngo/img/i/white.jpg)

<a id="fc2-mythical-灰字"></a>

#### 灰字

以 Socketed 物品作為素體。這類物品的名稱通常是灰字；帶 Socket 的普通白裝則是白字。

Socket 數量必須和要求符文數量相同；Socket 過多或不足都不能使用。例如要求符文是 Gra 與 Iza 時，只能使用 2 Socket 物品，1 Socket 或 3 Socket 都不行。

<a id="fc2-mythical-mod"></a>

#### Mod

部分 Socketed 物品會帶有天賦或技能強化，這些詞綴會在製作後保留下來。

部分 Socketed 物品名稱前會標示 Superior（右圖）。武器會額外帶有 Damage 強化，防具會額外帶有物理防禦強化；這些數值會在製作完成後加算。

<a id="fc2-mythical-商店"></a>

#### 商店

除了從地城拾取，Socketed 物品也可能在藥劑師、鐵匠鋪、商人販售。

商品會依角色而不同；更新時機推測是在城鎮中或離線狀態經過 1 小時。

<a id="fc2-mythical-製作"></a>

### 製作

<a id="fc2-mythical-socket"></a>

#### Socket

製作完成後，成品的 Socket 會被消耗，無法再進行 Enchant（附魔）。

用於製作的符文效果不會以 Enchant（附魔）形式保留在成品上。

<a id="fc2-mythical-依素體繼承"></a>

#### 依素體繼承

Damage、Speed、物理防禦等基礎性能會繼承素體數值。

製作防具時，材質也依素體決定；素體是布甲，成品也會是布甲。

<a id="fc2-mythical-需求等級"></a>

#### 需求等級

Mythic 物品的需求等級會採用素體與配方兩者之中較高的數值。

因此無法用精英素材的性能做出需求等級 9 之類的裝備。

<a id="fc2-mythical-技能-mod"></a>

#### 技能 Mod

若素體帶有天賦或技能強化，成品的 Mod 抽選會固定在該職業池內進行。

素體已經帶有的天賦不會和製作新增的天賦重複，會從抽選池中排除。

素體已經帶有的技能強化則可能和製作新增的技能強化重複。

<a id="fc2-mythical-乙太"></a>

#### 乙太

若素體帶有乙太，成品會繼承乙太；但耐久度不會恢復，會維持原本數值。

## 符文

- FC2 file：[rune.html](https://atelier3.web.fc2.com/ngo/rune.html)
- 原站 Last-Modified：`Mon, 23 Jun 2025 23:50:00 GMT`

符文可鑲嵌在單手武器、雙手武器、弓、Charm（護石）、盾牌、頭部與胴體等裝備的 Socket 中。

弓視為雙手武器；Charm（護石）視為單手武器，部分效果則視為防具；盾牌視為防具。

各難度首次通關 Lord Szarthax 後可向國王領取 King’s Reward；達到最低等級時會取得 1 顆免費符文。官方公告沒有公開普通（Normal）/ 惡夢（Nightmare）/ 地獄（Hell）各自的固定符文池；下列範圍是 FC2 玩家觀測，請以目前 Ladder 角色與遊戲內 UI 為準。

- 普通（Normal）：King’s Reward 最低 Lv25；官方公告沒有公開固定符文池，FC2 玩家觀測另註低 Lv 符文與 Lv45 符文。
- 惡夢（Nightmare）：King’s Reward 最低 Lv50；官方公告沒有公開固定符文池，FC2 玩家觀測到 Lv25～Lv59 符文。
- 地獄（Hell）：King’s Reward 最低 Lv90；1.2.24 已把 Hell 門檻提高到 Lv90，1.2.29 仍保留 Lv90，並限制 Hell King reward 最高為 Nex rune。FC2 玩家觀測範圍為 Lv39～Lv61。

<a id="fc2-runeselect-武器"></a>

### 武器

<a id="fc2-runeselect-物理-單手"></a>

#### 物理（單手）

Weapon Damage（Cros）＞All Passive（Targ）＞力量（Gart）

速度快、基礎值低的單手武器，多半最適合加算型的 Weapon Damage（Cros）。

不過即使是單手武器，若速度像 2.5 這樣偏慢，效率也不太好。

Weapon Damage（Cros）很稀有，也很難收集足夠顆數；過渡選項可以先用 All Passive（Targ），其次是力量（Gart）。Attack Rating%（Rath）也很優秀，但用在單手武器上有點可惜。

遊俠的單手武器採用 Attack Rating%（Rath）看起來不錯，但要有長期投資遊俠的心理準備。

<a id="fc2-runeselect-物理-雙手"></a>

#### 物理（雙手）

Attack Rating%（Rath）＞All Passive（Targ）＞力量（Gart）

速度慢、基礎值高的雙手武器，Weapon Damage（Cros）效率較低，常會接近 All Passive（Targ）。因此 Attack Rating%（Rath）最強；但 Rath 很稀有，而且需要的顆數也多，所以過渡選項可以先用 All Passive（Targ），其次是力量（Gart）。

例外是如果重視武器自動攻擊，Weapon Damage（Cros）會很強。All Passive（Targ）的最大值較高，但 Cros 對最低值的墊高效果較好。

<a id="fc2-runeselect-遊俠弓"></a>

#### 遊俠弓

Weapon Damage（Cros）、Weapon Speed（Rok）＞All Passive（Targ）＞力量（Gart）

遊俠弓比較特殊，效率會受武器基礎速度與 Socket 數量影響。

Elite Set 的 Sinifay's Golden Harrier 以 Weapon Damage（Cros）最優秀；Weapon Speed（Rok）的效率與 All Passive（Targ）大致相同。不過像 Reito Doku 這類速度快的弓，從第 3 個 Socket 開始，Weapon Speed（Rok）會超過 Weapon Damage（Cros）。詳情請看武器 DPS 計算機。

<a id="fc2-runeselect-非遊俠物理職業的弓-或-charm"></a>

#### 非遊俠物理職業的弓（或 Charm）

Attack Rating%（Rath）＞All Passive（Targ）＞力量（Gart）

可以用和物理雙手武器相同的方式思考。

不過武僧不能裝備弓，因此要改用 Charm；而 Charm 上的 Attack Rating%（Rath）會套用防具效果，所以 All Passive（Targ）會排到最優先。另外 Skill Speed（Phar）在 Charm 上也會變成防具效果，因此武僧吃不到這個收益。很苦。

<a id="fc2-runeselect-魔法"></a>

#### 魔法

Resistance Reduction（Mael）＞屬性 Damage ≒ 暴擊（Tae）

與物理不同，智慧（Ruck）與智力（Nag）這類能力值符文非常弱。

Resistance Reduction（Mael）很難取得，因此若目標是輸出，暴擊（Tae）應該最穩妥。

魔法符文不像物理符文那樣能大幅拉高火力，因此提高 Rare Drop Rate（Marr）也算不錯的選項。

另外，目前環境中的聖殿騎士不多，準備一把帶施法速度（Skar）的武器也很方便。

<a id="fc2-runeselect-命中率"></a>

#### 命中率

Attack Rating%（Rath）＞All Passive（Targ）＞Attack Rating（Shir）＞力量（Gart）

沒有提升 Attack Rating 天賦的魔法職業（特別是巫師）命中率會比較吃緊。為了提高 Proc 觸發率，也可以用符文補命中率。基本上 Attack Rating%（Rath）很優秀，但以單手武器基準來看差距只有約 0.5%，考量稀有度，All Passive（Targ）更穩。另外要注意，Attack Rating%（Rath）在 Charm 上會套用防具效果。若目標是提高 Proc 觸發率，用 Weapon Speed（Rok）調整攻速也可以納入選項。

<a id="fc2-runeselect-mana-回復"></a>

#### Mana 回復

命中時 Mana 回復（Gra）

武僧、十字軍等 Mana 消耗很重的職業，可以準備一件鑲了命中時 Mana 回復（Gra）的備用副裝備；隊伍裡沒有吟遊詩人時也會比較好運轉。

<a id="fc2-runeselect-防具"></a>

### 防具

<a id="fc2-runeselect-物理"></a>

#### 物理

全能力值（Rath）、Rare Drop Rate（Marr）

就火力而言，能提高力量的全能力值（Rath）很優秀，但把 Rath 消耗在防具上通常太奢侈，基本上沒有餘裕。如果某個抗性極端缺乏，屬性抗性符文當然也有用。

<a id="fc2-runeselect-魔法-2"></a>

#### 魔法

Rare Drop Rate（Marr）

可放的東西不多，因此用消去法會選 Rare Drop Rate（Marr）。不過 Marr 也算稀有，所以要嚴選要鑲的裝備。像 Mosby's Ancient Crown 這類能在多個角色間共用的裝備很推薦。

和物理一樣，如果某個抗性極端缺乏，就鑲屬性抗性符文。
